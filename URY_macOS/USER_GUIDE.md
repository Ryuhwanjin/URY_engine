## 1. URY Engine 소개 및 v0.2 핵심 업그레이드

**URY Engine (Ultimate Result for You Engine)**은 대학 강의 녹음 음성과 강의 슬라이드(PDF, PPTX, HWPX, DOCX) 및 칠판 판서 사진을 결합하여, **구글 최신 인공지능(Gemini)이 군더더기 없는 고밀도 학술 강의노트, 실전 모의시험, A4 1페이지 치트시트, 전범위 통합 바이블을 출판물급 PDF로 자동 제작**해주는 프리미엄 학업 솔루션입니다.

### ✨ v0.2 신규 기능 및 주요 업그레이드

| 영역 | 주요 업그레이드 내용 |
| :--- | :--- |
| 🍏 **Apple Clean Light 인터페이스** | macOS 정체성을 담은 미니멀 라이트 테마, 30px 높이의 둥근 모서리 플로팅 알약 탭바(Floating Pill Tab Bar), 인터랙티브 호버 애니메이션 전면 적용 |
| 🎛️ **2열 스튜디오 분할 레이아웃** | 좌측 파라미터 컨트롤 패널(과목, 일자, 녹음, 슬라이드)과 우측 실시간 진행 상태 카드 및 라이브 콘솔 분할로 직관성 극대화 |
| 🎙️ **내장 실시간 마이크 레코더** | 별도 녹음기 없이 Mac 내장 마이크 및 외장 마이크로 강의실 현장에서 즉시 고음질 원클릭 녹음/일시정지/저장 및 자동 수신함 인덱싱 |

| 📑 **멀티포맷 강의자료 완벽 지원** | PDF는 물론 마이크로소프트 파워포인트(`.pptx`), 한글(`.hwpx`), 워드(`.docx`) 문서를 별도 변환 없이 원본 그대로 연동 |

---

### 🔑 Google Gemini API 키 발급 (무료, 2분 소요)

> 💡 **API 키**는 구글 AI를 내 컴퓨터 프로그램과 연결해주는 개인 열쇠입니다. 매월 넉넉한 무료 사용량이 제공됩니다.

1. 웹 브라우저로 **[Google AI Studio](https://aistudio.google.com/app/apikey)** 에 접속합니다.
2. 구글 계정으로 **로그인**합니다.
3. 파란색 **`[Create API key]`** 버튼을 클릭합니다.
4. 팝업에서 **`[Create API key in new project]`**를 선택합니다.
5. 생성된 문자열(`AIzaSy...` 등) 우측의 **`[Copy]`** 버튼을 눌러 복사합니다.

## 3. OS별 빠른 시작 및 설치 가이드

### 🍏 macOS 사용자 가이드

#### 1. 패키지 다운로드 및 압축 해제
- `URY_macOS_v0.2_Release.zip`을 다운로드하고 압축을 풉니다.
- 압축 해제된 폴더를 **[바탕화면]** 또는 **[응용 프로그램(Applications)]** 폴더로 이동합니다.

#### 2. URY Engine.app 원클릭 실행
- 폴더 내의 **`URY Engine.app`**을 더블클릭합니다.
- 파이썬이 설치되어 있지 않은 환경에서도 독립적으로 즉시 실행됩니다.

#### 3. macOS 미확인 개발자 보안 경고 해결법 (최초 1회)
인터넷에서 다운로드한 앱은 애플 게이트키퍼(Gatekeeper)에 의해 차단될 수 있습니다. 아래 3가지 방법 중 하나를 선택하세요:
- **방법 1 (가장 간단)**: `보안경고_자동해제.command`를 더블클릭합니다. (격리 속성 자동 해제)
- **방법 2 (우클릭 열기)**: `URY Engine.app` 위에서 마우스 우클릭 ➔ **[열기]** ➔ 경고창에서 **[열기]** 클릭
- **방법 3 (시스템 설정)**: 화면 좌측 상단 애플 마크() ➔ **[시스템 설정]** ➔ **[개인정보 보호 및 보안]** ➔ 보안 섹션의 **`[확인 없이 열기]`** 클릭

---

### 🪟 Windows OS 사용자 가이드

#### 1. 패키지 다운로드 및 압축 해제
- `URY_Windows_v0.2_Release.zip`을 다운로드하고 원하는 폴더(예: `C:\URY_Engine` 또는 바탕화면)에 압축을 풉니다.

#### 2. 원클릭 실행 (`URY_Engine_실행.bat`)
- 폴더 내의 **`URY_Engine_실행.bat`** 파일을 더블클릭합니다.
- 파이썬 설치 여부를 자동으로 확인하고, 부족한 필수 패키지(`pymupdf`, `markdown`, `requests`, `pypdf`)를 스스로 설치한 후 대시보드가 열립니다.
- *(선택 사항)* 단독 실행 파일(`.exe`)로 만들고 싶다면 **`빌드_Windows_EXE.bat`**를 더블클릭하면 `dist/URY Engine.exe`가 자동 빌드됩니다.

#### 3. 웹 브라우저 조판 엔진
- 출판용 고화질 PDF 렌더링을 위해 **Google Chrome** 또는 Windows 기본 브라우저인 **Microsoft Edge**가 자동으로 연동됩니다.

---

### ⚙️ 공통 초기 설정 (API 키 등록 및 과목 등록)

1. 앱 실행 후 **`[⚙️ 과목 및 시스템 설정]`** 탭으로 이동합니다.
2. `Google Gemini API Key` 입력란에 복사한 키를 붙여넣습니다 (`Cmd + V` 또는 `Ctrl + V`).
3. 하단의 **`[💾 설정 저장]`** 버튼을 클릭합니다.
4. **수강 과목 등록**:
   - 시간표 및 과목 목록에서 이번 학기 수강 과목명, 요일, 수업 시간을 입력하고 저장합니다.
   - 저장 시 `2026년 2학기/[과목명]` 폴더 구조가 자동으로 생성됩니다.

- 서약 조항을 확인하고 **`[동의 후 계속하기]`**를 클릭하면 모든 기능이 활성화됩니다.

### 🎙️ 5.1 내장 실시간 오디오 레코더 (Live Native Recorder)
스마트폰을 꺼낼 필요 없이, 노트북을 열고 강의실에서 바로 녹음할 수 있습니다.
1. **`[🔴 즉석 녹음 시작]`** 버튼을 클릭합니다.
2. Mac 내장 마이크를 통해 수업 내용이 고음질로 실시간 녹음되며, 경과 시간이 초 단위로 표시됩니다.
3. 수업이 끝나면 **`[⏹️ 녹음 완료 및 저장]`**을 누릅니다.
4. 녹음 파일이 해당 과목의 일자 및 주차 규격에 맞춰 `00_녹음_수신함` 및 과목 폴더에 자동으로 저장되고 선택됩니다.

### 📸 5.2 칠판 판서 사진 Vision 멀티모달 분석
- 교수님이 칠판에 적으신 공식 유도 과정, 그래프, 다이어그램 사진을 스마트폰으로 찍은 후 **`[➕ 칠판 사진 선택]`**을 통해 추가하세요.
- Gemini Vision 인공지능이 손글씨 수식과 도표를 해독하여 본문 `[💡 칠판 판서 및 도표 해석]` 섹션에 정밀하게 삽입해 줍니다.

### 🛑 5.3 작업 즉시 중단 (Kill) 안전장치
- 작업 도중 네트워크 지연이나 설정 실수로 중단하고 싶을 때, 우측 하단의 **`🛑 [작업 즉시 중단 (Kill)]`** 버튼을 누르면 백그라운드 프로세스가 즉시 안전하게 종료되고 초기 상태로 복구됩니다.

### 1️⃣ ⚡ 시험 직전 3분 치트시트 (A4 딱 1페이지)

- **4대 핵심 구성**:
  1. 🔑 **초핵심 공식 & 절대 암기 정의**: 수식($...$) 및 1줄 정의
  2. ⚠️ **교수님 강조 함정 & 빈출 오답 포인트**: 오답 함정 대조표

  4. 🎯 **단답/약술형 예상 1순위 키워드 TOP 5**: 시험 1순위 키워드 및 모범 문구

### 2️⃣ 📝 맞춤형 실전 모의시험 & ✍️ AI 정밀 자동 채점기
- 100% 실제 수업 자료와 교수님 강조 발언을 토대로 출제되는 모의시험입니다.
- 시험지(문제)와 정답/해설지 사이에 자동 페이지 분할이 적용되어 있습니다.
- **AI 자동 채점기 연동**:
  1. 모의시험을 푼 후 **`[✍️ 답안 제출 및 AI 자동 채점]`**을 클릭합니다.
  2. 나의 답안(객관식 번호 및 서술형 답변)을 입력하고 채점을 시작합니다.
  3. **객관식**: 정답표 1:1 대조 채점 (맞춤/틀림)
  4. **서술형**: 핵심 키워드 포함도(60%) + 논리 전개 완성도(40%) 부분 점수 부여
  5. 총점(100점 만점), 예상 등급(A+/B+), 취약점 분석 및 맞춤 복습 권고 리포트 발행

### 3️⃣ 📖 전범위 마스터 바이블 (Master Course Bible)
- 1주차부터 16주차까지의 모든 강의노트를 통합하여 목차, 색인, 페이지 번호가 완비된 **1권의 디지털 전공 교재**로 자동 편찬합니다.

### 4️⃣ 📅 종강 D-Day 맞춤형 학습 로드맵
- 시험일까지 남은 일수를 계산하여 일자별 학습 목표, 복습 분량, 취약 단원 집중 일정을 캘린더 형식으로 제공합니다.

## 9. 핵심 기능 5: 원클릭 일괄 파이프라인 자동화

모든 과목의 신규 녹음본을 한 번에 일괄 처리하고 싶을 때 사용합니다.

1. 스마트폰 녹음 파일을 `00_녹음_수신함` 폴더에 넣습니다.
2. **`파이프라인_실행.command`** (Windows는 `파이프라인_실행.bat`)를 더블클릭합니다.
3. 6단계 전체 자동 파이프라인이 순차 실행됩니다:
   - **Stage 1**: 파일명 분석 및 과목/주차 자동 분류
   - **Stage 2**: Gemini API 호출 및 심층 학술 강의노트 작성 (타임스탬프 네비게이터)
   - **Stage 3**: 강의 슬라이드 고화질 이미지 자동 추출 및 연계
   - **Stage 4**: Pretendard 서적 스타일 출판용 PDF 렌더링
   - **Stage 5**: 과목별 실전 모의시험 & 맞춤 로드맵 자동 편찬
   - **Stage 6**: `.마크다운_강의노트` 중앙 보관함 동기화 및 종합 리포트 발행
4. 작업이 끝나면 운영체제 알림과 함께 최종 리포트가 팝업됩니다.

## 12. 자주 묻는 질문 및 트러블슈팅 FAQ

### Q1. 강의노트 생성이 1분 내외로 걸립니다. 정상인가요?
- **네, 완벽히 정상입니다.** 1시간 분량의 전공 오디오를 구글 클라우드 인공지능이 분석하고 슬라이드 이미지와 결합하여 고품질 PDF로 조판하는 데 평균 40~80초가 소요됩니다.

### Q2. 슬라이드 자료 선택 시 권장 사항이 있나요?
- 수백 페이지 분량의 전공 원서 교재 전체보다, **해당 주차에 수업한 슬라이드(10~40페이지)**를 선택할 때 가장 빠르고 완성도 높은 결과가 생성됩니다.

### Q3. "HTTP 429" 또는 "HTTP 503" 에러가 뜨면 어떻게 하나요?
- URY Engine에는 **구글 서버 과부하 대응 지수 백오프 자동 재시도**가 내장되어 있습니다. 일시적인 트래픽 급증 시 자동으로 대기 후 재시도하며 가용 모델로 전환하므로 별도 조치가 필요하지 않습니다.

### Q4. 구글 Gemini API 키 발급은 유료인가요?
- **완전 무료입니다.** Google AI Studio에서 발급하는 API 키는 매달 학부생이 사용하기에 충분하고 넉넉한 무료 한도를 제공합니다.

### Q5. 작업 도중 프로그램을 강제 종료하고 싶으면 어떻게 하나요?
- 스튜디오 우측 하단의 **`🛑 [작업 즉시 중단 (Kill)]`** 버튼을 누르면 모든 프로세스가 깔끔하게 정지되고 즉시 재사용 가능한 상태가 됩니다.
