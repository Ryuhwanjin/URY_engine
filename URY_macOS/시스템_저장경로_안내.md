# 📂 URY Engine v0.7.5 - 시스템 저장 경로 및 폴더 역할 안내

본 문서는 **URY Engine** 애플리케이션의 내부 실행 폴더와 사용자 작업 폴더 간의 저장 구조를 상세히 안내합니다.

---

### 1. ⚙️ [앱 실행 전용 보호 영역] 내 문서 (Documents)
* **저장 경로**: `C:\Users\<사용자계정>\Documents\URY_Engine\` (macOS: `~/Documents/URY_Engine/`)
* **특징**: **사용자가 수동으로 변경하거나 건드릴 필요가 없는 앱 전용 핵심 시스템 저장소**
* **상세 구성**:
  - `system/settings.json`: API 키, 과목 환경 설정 및 학기 정보
  - `system/code/`: 파서, AI 요약 엔진, GUI 파이썬 모듈
  - `system/cache/`: PDF 빠른 처리를 위한 인덱싱 및 빠른 렌더링 캐시 (.markdown_cache)
  - `system/logs/`: 처리 실행 및 시스템 오류 로그

> 💡 **주의**: `Documents/URY_Engine/` 내부 파일은 애플리케이션의 정품 동작을 위해 관리되는 전용 시스템 파일입니다. 사용자가 수동으로 수정하지 않아도 최신 GUI 설정 관리자에서 자동으로 동기화됩니다.

---

### 2. 📁 [사용자 작업 영역] 바탕화면 (Desktop)
* **저장 경로**: `C:\Users\<사용자계정>\Desktop\URY_Engine\` (macOS: `~/Desktop/URY_Engine/`)
* **특징**: **사용자가 직접 교재 PDF를 넣고 렌더링된 결과물을 확인하는 작업 폴더**
* **상세 구성**:
  - `00_녹음_수신함/`: 음성 녹음 MP3/M4A/WAV 파일 투입소
  - `2026년 2학기/[과목명]/강의자료/`: 교재 PDF, DOCX, PPTX 저장소
  - `2026년 2학기/[과목명]/마크다운_학습노트/`: 자동 생성된 PDF 학습노트 및 족보

---

### 3. 🗑️ 프로그램 클린 완전 삭제 (Uninstaller)
* **삭제 방법**: `04_완전삭제.bat` (또는 `프로그램_완전삭제.bat`) 실행
* **삭제 범위**:
  - `Documents/URY_Engine` 보호 영역 전체 삭제
  - `Desktop/URY_Engine` 독립 실행 자원 전체 삭제
  - 빌드 임시 파일 및 캐시 100% 클린 완전 제어
