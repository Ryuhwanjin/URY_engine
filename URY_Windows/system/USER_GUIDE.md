## 1. URY Engine이 뭔가요?

**URY Engine (Ultimate Result for You Engine)**은 대학 강의 녹음 음성과 강의 슬라이드(PDF)를 결합하여, **구글 최신 인공지능(Gemini)이 군더더기 없는 고밀도 학술 강의노트와 실전 모의시험, A4 1페이지 치트시트를 전자책/출판물급 PDF로 자동 제작**해주는 프리미엄 학업 솔루션입니다.

### ✨ 무엇이 새로워졌나요? (v0.1 핵심 업그레이드)

| 영역 | 주요 업그레이드 내용 |
| :--- | :--- |
| 💬 **"교수님 말씀 Q&A" AI 강의 전용 튜터** | 과목별 누적 강의노트, 슬라이드, 치트시트를 RAG 지식 베이스로 연동하여 **교수님 실제 육성 발언 시점([🎙️ 음성 (MM:SS)])과 시험 팁을 정확히 인용하며 1:1 과외**를 제공하는 전용 챗봇 탑재 |
| ✍️ **실전 모의시험 AI 정밀 자동 채점기** | 객관식(1:1 정답 대조), 서술형/손풀이(키워드 60% + 논리 전개 40% 부분 점수 부여)를 반영하여 **총점(100점 만점), 예상 학점 등급(A+/B+), 문항별 상세 피드백 및 취약점 분석 리포트** 자동 발행 |
| 📌 **슬라이드-음성 타임스탬프 정밀 앵커링** | 음성 타임스탬프 언급 구간과 슬라이드 시각 자료를 정밀 대조하여 **핵심 다이어그램 캡션에 `(🎙️ MM:SS 음성 연계)` 타임스탬프 자동 앵커링** |
| 📦 **최초 실행 시 pip install 자동 수행** | 앱 실행 시 부족한 파이썬 라이브러리를 사용자 개입 없이 **백그라운드에서 자동 감지 및 설치 (`ensure_requirements.py`)** |
| 💻 **Windows OS & macOS 완벽 지원** | macOS(`.command`)뿐만 아니라 Windows OS(`.bat` 원클릭 런처, Microsoft Edge / Chrome 자동 감지)를 완벽 지원 |
| ⚡ **시험 직전 3분 A4 1페이지 치트시트** | 시험 당일 고사장 입실 직전 3분 동안 볼 수 있는 **A4 딱 1페이지 초고밀도 요약본(공식/함정/매트릭스/TOP5)** 원클릭 조판 |
| ⏱️ **음성 타임스탬프 네비게이터** | 강의노트 본문의 `[🎙️ 음성 (14:25)]` 태그에 **실제 발언 재생 시간 자동 인덱싱** ➔ 원본 음성 즉시 재청취 가능 |
| 📊 **주차별 진도 모니터링 대시보드** | 1~16주차 전 차시의 **녹음 수신, 국/영문 강의노트, 슬라이드, 모의시험 진행률**을 실시간 카드 & 테이블로 시각화 |

## 2. 시작 전 필수 준비물

### ✅ 필수 체크리스트
- [ ] **Mac 또는 PC** (macOS 권장)
- [ ] **Google 계정** (무료 AI API 키 발급용)
- [ ] **인터넷 연결** (클라우드 AI 분석용)
- [ ] **강의 녹음 파일** (`.m4a`, `.mp3`, `.wav` 모두 지원) 및 **강의 슬라이드** (`.pdf`)

---

### 🔑 Google Gemini API 키 발급 (무료, 2분 소요)

> 💡 **API 키**는 구글 AI를 내 컴퓨터 프로그램과 연결해주는 개인 열쇠입니다.

1. 크롬 브라우저로 **[Google AI Studio](https://aistudio.google.com/app/apikey)** 에 접속합니다.
2. 구글 계정으로 **로그인**합니다.
3. 파란색 **`[Create API key]`** 버튼을 클릭합니다.
4. 팝업에서 **`[Create API key in new project]`**를 선택합니다.
5. 생성된 문자열(`AIzaSy...` 등) 우측의 **`[Copy]`** 버튼을 눌러 복사합니다.

## 3. 처음 1회만 하는 초기 세팅

### 📦 Step 1. 압축 해제 및 폴더 배치
- 다운로드받은 `URY_macOS.zip`의 압축을 풀고, 생성된 `URY_macOS` 폴더를 **[바탕화면]** 또는 **[문서]** 폴더에 배치합니다.

### 🔓 Step 2. macOS 보안 차단 및 미확인 개발자 경고 완벽 해결법 (최초 1회)
인터넷에서 다운로드한 스크립트 파일(`.command`)은 애플 게이트키퍼(Gatekeeper)에 의해 기본 차단될 수 있습니다. 아래 3가지 중 편한 방법을 선택하세요:

#### 🌟 방법 1. [가장 확실한 추천] Mac 시스템 설정에서 [확인 없이 열기]
1. `설정관리자.command`를 더블클릭합니다.
2. 경고 팝업이 뜨면 **`[완료]`**를 누릅니다.
3. Mac 화면 좌측 상단 **애플 마크() ➔ [시스템 설정] ➔ [개인정보 보호 및 보안]**으로 들어갑니다.
4. 아래로 스크롤하여 **보안** 섹션에 `"설정관리자.command"이(가) 차단되었습니다` 문구 옆의 **`[확인 없이 열기]`** 버튼을 누릅니다.
5. Mac 암호(또는 Touch ID)를 입력하고 **`[열기]`**를 클릭합니다.

#### 💡 방법 2. 마우스 우클릭으로 바로 열기
1. **`설정관리자.command`** 파일 위에서 **마우스 우클릭** (또는 키보드의 `Control` 키를 누른 채 클릭)
2. 메뉴에서 **`[열기]`** 선택
3. 화면에 경고창이 나타나면, 하단의 **`[열기]`** 버튼을 클릭합니다.

#### ⚡ 방법 3. `보안경고_자동해제.command` 원클릭 실행
#### 🪟 Windows 사용자 원클릭 실행법
1. 다운로드받은 `URY_Windows.zip` 압축을 해제합니다.
2. 폴더 내의 **`설정관리자.bat`** 파일을 더블클릭합니다.
3. 최초 실행 시 부족한 필수 파이썬 패키지(`pymupdf`, `markdown`, `requests`, `pypdf`)가 자동으로 `pip install`된 후 대시보드가 열립니다.
4. (PDF 렌더링을 위해 Google Chrome 또는 Windows 기본 브라우저인 Microsoft Edge가 설치되어 있으면 즉시 연동됩니다.)

1. 폴더 내의 **`보안경고_자동해제.command`** 파일을 더블클릭합니다.
2. 터미널 창이 열리며 폴더 내 모든 파일의 보안 격리 속성(`com.apple.quarantine`) 및 실행 권한(`chmod +x`)이 자동으로 일괄 해제됩니다.

---

### ⚙️ Step 3. 설정관리자 실행 및 API 키 등록
1. **`설정관리자.command`**를 더블클릭하여 대시보드를 엽니다.
2. **`[⚙️ 과목 및 시스템 설정]`** 탭으로 이동합니다.
3. `Google Gemini API Key` 입력란에 복사한 키를 붙여넣습니다 (`Cmd + V`).
4. 하단의 **`[💾 설정 저장]`** 버튼을 클릭합니다.

### 📚 Step 4. 수강 과목 등록
- 과목 목록에서 과목명, 요일, 수업 시간 등을 확인/수정합니다.
- 등록 완료 후 **`[💾 설정 저장]`**을 누르면 시간표와 폴더 구조가 자동으로 동기화됩니다.

## 4. 핵심 기능 1: 맞춤형 학습노트 생성 스튜디오 (강력 추천)

**[🎙️ 맞춤형 학습노트 생성 스튜디오]** 탭에서 원하는 수업만 선택하여 즉석에서 초고속으로 노트를 생성할 수 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐

│  [Step 2. 녹음 파일]     [과목보관] 2026-09-01_마케팅원론_1주차.m4a    │

│                                                                        │
│               [ ⚡ 맞춤형 학습노트 생성 시작 ]                           │

│ [10:05:01] 🚀 [마케팅원론] 맞춤형 학습노트 생성 파이프라인 가동          │
│ [10:05:03] ℹ️ [구글 최신 모델 순서 자동 감지]: gemini-flash-latest ... │
```

### 🚀 3단계 초간단 사용 순서

1. **과목 & 일자 선택**: 대상 과목을 고르고 날짜와 주차를 지정합니다.
2. **음성 자료 선택**:
   - 수신함이나 과목 보관함의 오디오 파일을 선택합니다.
   - 만약 **녹음을 못 한 수업이라면?** ➔ **`☑ 음성 녹음 없음 (슬라이드 집중 분석 모드)`**를 체크하세요!
3. **슬라이드 PDF 선택**:
   - 수업에서 사용된 해당 주차의 강의 슬라이드 PDF를 체크합니다.
4. **언어 선택 & 생성 시작**:
   - 한국어 시험 대비라면 **`한글 전용`**을 선택하세요 (생성 시간 50% 단축).
   - **`[⚡ 맞춤형 학습노트 생성 시작]`**을 클릭합니다.
5. **실시간 모니터링 및 PDF 확인**:
   - 하단 콘솔창에서 타임스탬프와 함께 진행 상황과 실시간 ETA 카운트다운을 확인합니다.
   - 작업 완료 알림이 뜨면 **`[📄 생성된 PDF 열기]`**를 클릭하여 완성된 출판용 문서를 즉시 감상합니다!

### 🛑 작업 즉시 중단 (Kill) 및 콘솔 제어
- 작업 도중 네트워크 오류나 API 응답 지연이 발생하더라도 프로그램을 강제 종료할 필요가 없습니다.
- 콘솔 우측 하단의 **`🛑 [작업 즉시 중단 (Kill)]`** 버튼을 누르면 즉시 안전 복구됩니다.

## 5. 핵심 기능 2: 실전 모의시험 & 맞춤 로드맵 & 3분 치트시트

중간고사 / 기말고사 시험 기간에 실전 감각을 극대화하기 위한 시험 대비 전용 탭입니다.  
과목별 시험 범위에 맞춰 **100% 실제 수업 자료 기반의 고품질 모의시험**, **종강 D-Day 학습 로드맵**, 그리고 시험 직전 필수인 **3분 A4 1페이지 치트시트**를 원클릭으로 제작합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│  [1. 시험 기본 설정]  과목: [ DB 기초 및 응용 ▼ ]  시험: [ 중간고사 ▼ ]      │
│  [2. 문항 및 유형]    문항수: [ 10문항 ▼ ]  유형: [ 객관식 (4지선다) ▼ ]      │
│  [3. 출제 범위 자료 다중 선택 (Checklist)]                             │
│     [전체 선택]  [전체 해제]  [➕ 외부 파일 추가]                         │
│     [✓] 1주차_강의노트.md (38.2 KB)                                    │
│     [✓] 2주차_강의노트.md (42.1 KB)                                    │
│     [✓] 3주차_강의노트.md (35.0 KB)                                    │
│     [✓] Slide_Ch01_Intro.pdf (2.4 MB)                                 │
│                                                                        │
│            [ 📅 종강 D-Day 맞춤형 학습 로드맵 PDF 생성 ]                 │
│            [ 📝 지정 범위 맞춤형 실전 모의시험 PDF 즉시 출제 ]            │
│            [ ⚡ 시험 직전 3분 치트시트(1Page) PDF 생성 ]                 │
└────────────────────────────────────────────────────────────────────────┘
```

### 🎯 실전 모의시험 & 치트시트 주요 특징
1. **⚡ 시험 직전 3분 치트시트 (A4 1-Page Cheat Sheet)**:
   - 시험 고사장 입실 직전 3분 동안 볼 수 있는 **초고밀도 A4 1장 요약본**을 생성합니다.
   - **4대 필수 구성**:
     - 🔑 **초핵심 공식 & 절대 암기 정의**: 시험 필수 수식($...$) 및 핵심 정의 1줄 요약
     - ⚠️ **교수님 강조 함정 & 빈출 오답 포인트**: 헷갈리기 쉬운 대립 개념 쌍 및 오답 함정 피하기 팁
     - 📊 **핵심 키워드 3열 매트릭스**: `용어 | 영문 표기 | 1줄 핵심 정의 및 출제 포인트` (6~8개)
     - 🎯 **단답/약술형 예상 1순위 키워드 TOP 5**: 시험 1순위 출제 예상 키워드 및 모범 답안 핵심구
   - 초고밀도 조판 스타일이 적용된 단일 PDF로 제공되며, 중간 마크다운(`.md`) 파일은 자동 영구 삭제됩니다.
2. **출제 범위 다중 자료 선택 (Multi-file Scope)**:
   - 1주차부터 7주차까지 중간고사 전 범위의 강의노트(`.md`)와 슬라이드(`.pdf`)를 체크박스로 한 번에 지정할 수 있습니다.
   - **`[➕ 외부 파일 추가]`** 버튼을 눌러 교수님이 별도로 올려주신 보충 자료나 과제 PDF도 출제 범위에 즉시 포함할 수 있습니다.
3. **100% 수업 기반 범용 출제 (Content-Grounded Engine)**:
   - 특정 교재나 과목에 편향되지 않고, 오직 **제공된 실제 수업 자료 본문**만을 100% 바탕으로 문제를 정교하게 출제합니다.
   - 객관식(4지선다), 서술형/손풀이(계산 유도 과정), 혼합형 중 원하는 문제 유형을 선택할 수 있습니다.
4. **시험지 + 정답 및 오답 해설 분리 조판**:
   - 시험 문제지(Part 1)와 정답/상세 해설(Part 2) 사이에 **자동 페이지 분할**이 적용되어, 해설이 시험지 바로 뒤에 보이지 않고 항상 새 페이지에서 시작합니다.

### 🎓 AI 튜터 주요 특징 & 과목별 전담 조교 체계
1. **과목별 독립 AI 튜터 & 맞춤 조교 닉네임 (`tutor_name`)**:
   - 과목마다 서로 다른 전담 튜터 인스턴스가 배정되며, 탭 상단의 **`[🏷️ 조교 닉네임 변경]`** 또는 **`[⚙️ 과목 및 시스템 설정]`**에서 원하는 닉네임(예: *"데베박사"*, *"회계요정"*, *"자비스"*, *"수석조교"* 등)을 자유롭게 명명할 수 있습니다.
   - 과목을 자유롭게 전환하더라도 이전 과목의 대화 기록이 지워지지 않고 **과목별로 독립 세션이 100% 안전 보존**됩니다.
2. **강의계획서(Syllabus) 2-Track 하이브리드 연동**:
   - 대학 정규 강의뿐만 아니라 자격증/독학/온라인 강좌 사용자까지 배려하여 **강의계획서 업로드를 강력 권장(Recommended)**하되 필수로 강제하지 않습니다.
   - 🟢 **[강의계획서 연동 모드]**: `[📑 강의계획서 등록]` 버튼을 통해 실라버스 PDF를 등록하면, **공식 주차별 진도표, 중간/기말 시험 범위 및 일정, 평가 배점 비율(%)을 100% 마스터 기준**으로 삼아 답변 및 학습 플랜을 설계합니다.
   - 🟡 **[자율 지능 추론 모드]**: 강의계획서가 없는 과목이라도 멈추지 않고, 누적된 슬라이드와 강의노트 목차를 인공지능이 스스로 분석하여 유연하게 최적의 학습 로드맵과 질의응답을 제공합니다.
3. **3대 환각(할루시네이션) 방지 안전장치**:
   - 📖 **실제 참조 원문 스니펫 강제 출력**: 답변 하단에 `📌 [참조 원문 근거: X주차 강의노트 L12-25]`를 명시하여 학생이 직접 검증할 수 있습니다.
   - ⚠️ **상단 안전 면책 배너**: AI 튜터 탭 상단에 학업 참고용 면책 고지 배너를 상시 배치합니다.
   - 🔄 **2단계 사실 검증 가드레일**: 인용된 타임스탬프와 핵심 키워드가 실제 지식 베이스에 실존하는지 검증합니다.
4. **이원화 지식 구조 (Dual-Source Knowledge)**:
   - 강의 자료에 존재하는 내용은 철저히 교수님 수업 근거로 답변합니다.
   - 슬라이드에 없는 원론적 기초 지식이나 수학 공식(선수 지식) 질문도 매몰차게 거부하지 않고, `[💡 전공 기초 개념 보충]` 섹션으로 명확히 분리하여 친절하게 해설합니다.
5. **교수님 발언 타임스탬프 인용 ([🎙️ 음성 (MM:SS)])**:
   - 단순 교과서 지식이 아닌, '우리 교수님이 수업 중 직접 하신 말씀'과 강조 포인트를 타임스탬프와 함께 명쾌하게 짚어줍니다.
6. **원클릭 빠른 질문 칩 & 멀티턴 대화**:
   - `💡 시험 필수 강조 개념`, `🎙️ 교수님 시험 팁 & 주의사항`, `📝 핵심 공식 3분 요약`, `❓ 서술형 답안 필수 키워드` 버튼을 누르면 즉시 맞춤 답변을 받아볼 수 있습니다.

## 8. 핵심 기능 5: 원클릭 일괄 파이프라인 자동화

학기 중 또는 주말에 모든 과목의 신규 녹음본을 한 번에 일괄 처리하고 싶을 때 사용합니다.

1. 스마트폰 녹음 파일을 `00_녹음_수신함` 폴더에 넣습니다.
2. **`파이프라인_실행.command`**를 더블클릭합니다 (또는 대시보드에서 실행).
3. 6단계 전체 자동 파이프라인이 순차 가동됩니다:
   - **Stage 1**: `00_녹음_수신함` 오디오 파일 과목별 주차별 자동 분류
   - **Stage 2**: Gemini API 호출 및 심층 강의노트 생성 (타임스탬프 네비게이터 적용)
   - **Stage 3**: 강의 슬라이드 PDF 고화질 다이어그램 자동 추출 & 연계
   - **Stage 4**: Pretendard 서적 스타일 출판용 PDF 렌더링
   - **Stage 5**: 과목별 실전 모의시험 & 맞춤 로드맵 자동 출제
   - **Stage 6**: `.마크다운_강의노트` 중앙 보관함 동기화 & 종합 리포트 발행
4. 완료 시 **macOS 상단 알림센터 팝업**과 함께 최종 리포트가 출력됩니다.

## 9. 고품질 출판용 PDF 및 강의노트 4단계 표준 구조

URY Engine이 발행하는 모든 PDF 강의노트는 아래 4단계 표준 구조를 철저히 준수합니다.

```markdown
# [과목명] [N]주차 맞춤 강의노트
> **과목명**: [과목명] | **주차**: [N]주차 | **일자**: YYYY-MM-DD (요일)

## 📌 1. 수업 개요 및 주요 공지사항 [🎙️ 음성 (MM:SS)]
- 시험 출제 힌트, 과제 마감일, 출석 코드 등을 발언 타임스탬프와 함께 완벽 정리

## 💡 2. 핵심 이론 및 상세 개념 분석 [출처 태그 명시]
- 잡소리(사담, 농담)는 100% 배제하고, 순수 학술 이론과 공식을 체계적 소제목으로 심층 해설
- `[🎙️ 음성 (MM:SS)]` : 교수님 육성 부연설명 및 현장 비유 (음성 시작 시점 분:초 병기)
- `[📖 교재·슬라이드]` : 슬라이드 정의 및 원서 수식
- `[💡 통합 (MM:SS)]` : 이론과 실전 사례가 결합된 핵심 내용

## 🎯 3. 핵심 키워드 정리 & 단원 종합 요약
```

## 11. 자주 묻는 질문 및 트러블슈팅 FAQ

### Q1. 맞춤형 강의노트 생성이 1분 이상 걸려요. 정상인가요?
- **네, 100% 정상입니다.** 수십 분짜리 전공 수업 오디오를 구글 클라우드 AI가 정밀 분석하고, 슬라이드 이미지와 결합하여 고품질 PDF로 조판하는 데 평균 40~90초가 소요됩니다.

### Q2. 슬라이드 파일 선택 시 주의할 점이 있나요?
- 수백 페이지 분량의 전공 원서 교재 전체 PDF 대신, **해당 주차에 진행된 강의 슬라이드 PDF(10~40페이지)**를 선택할 때 가장 빠르고 완성도 높은 결과가 생성됩니다.

### Q3. "HTTP 503" 또는 "HTTP 429" 에러가 콘솔에 뜨면 어떻게 하나요?
- URY Engine v0.0에는 **구글 서버 과부하 지수 백오프 자동 재시도(Exponential Backoff)**가 탑재되어 있습니다. 503/429 발생 시 5초, 10초, 20초 간격으로 최대 3회 자동 재시도하며, 해결되지 않을 경우 다음 가용 모델로 즉시 자동 전환되므로 사용자가 신경 쓸 필요가 없습니다.

### Q4. "Gemini API Key가 설정되지 않았습니다"라고 떠요.
- `설정관리자.command`를 실행한 후 **[⚙️ 과목 및 시스템 설정]** 탭에서 복사한 Gemini API Key를 붙여넣고 **[💾 설정 저장]**을 눌러주세요.

### Q5. 구글 API 키 발급은 유료인가요?
- **완전 무료입니다.** Google AI Studio에서 발급하는 API 키는 매달 넉넉한 무료 사용량(RPM/RPD)을 제공하여 학부 전공 수업 관리에 충분합니다.

### Q6. 작업 도중 오류가 나거나 멈추면 앱을 껐다 켜야 하나요?
- 앱을 끌 필요가 없습니다! 콘솔 우측 하단의 **`🛑 [작업 즉시 중단 (Kill)]`** 버튼을 누르면 즉시 모든 상태가 초기화되어 안전하게 다시 시작할 수 있습니다.

### Q7. "확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다"라는 보안 경고가 떠요.
- [3. 처음 1회만 하는 초기 세팅] 가이드의 **Step 2 (방법 1 또는 방법 3 `보안경고_자동해제.command`)**를 실행하시면 즉시 해결됩니다.
